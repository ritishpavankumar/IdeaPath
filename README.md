# IdeaPath

An experimental AI-assisted project exploring how personal goals can be turned into actionable roadmaps, milestones, and tasks.

## Overview
IdeaPath is a small productivity-style app where an idea or goal can be broken down into milestones and tasks, with progress tracked over time. It also includes an AI chat assistant ("Goal Coach") that helps turn a stated goal into a milestone/task plan conversationally.

## What I Was Exploring
This project was about exploring how far an idea could be taken — from concept to a working, deployed app — using an AI-assisted, no-code workflow, and how AI-based planning assistance could help structure personal goals into concrete steps.

## Project Status
Experimental — First Experimental Project. This is not a professionally engineered or production-ready application. It was built to learn and experiment, not to scale or serve real users.

## AI-Assisted Development
This project was built using an AI-assisted no-code workflow with Base44. AI tooling handled the majority of the actual implementation (frontend, backend logic, and data structure). I did not manually write the application's code.

## My Role
- Chose the project idea and overall direction
- Defined what I wanted the application to explore
- Wrote prompts/instructions and follow-up requests
- Reviewed AI-generated outputs
- Decided what to keep, change, or iterate on
- Used the available AI tools to move the project toward a usable result
